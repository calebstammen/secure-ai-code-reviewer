# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please report it privately:

- Email: security@example.com
- Provide reproduction steps, impacted versions, and any relevant logs (redact secrets).

We will acknowledge receipt within 72 hours and provide a timeline for remediation.

## Responsible Disclosure
Please avoid public disclosure until a fix is available. We will coordinate a release and credit reporters when appropriate.
